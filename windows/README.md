# A股桌面行情 · Windows

依据 [LingDaoyun/StockDashboard](https://github.com/LingDaoyun/StockDashboard) 的 macOS 版功能制作的原生 Windows 客户端。原版提交：`fc28d0135532befcac2da98eef0055b26d98a905`。macOS 源码保持不变。

## 打开

直接双击 `dist/StockDashboard.exe`。也可解压便携 ZIP 后双击同名 EXE。无需管理员权限，支持 Windows 10/11（.NET Framework 4.8）；本机已安装运行环境。

首次没有预设自选股。默认自动吸附在屏幕右侧，移入蓝色「行情」提示条展开。若没有看到主窗口，可双击系统托盘的行情图标，或右键图标选择「显示行情」。部分托盘图标位于任务栏右下角折叠菜单中。

## 操作

- 顶部 `＋`：输入中文简称，稍停出现候选；输入六位代码按回车添加，多个代码可用逗号分隔；支持沪、深、北交所，最多20只。多个名称结果需要点选，不会擅自猜测。Esc收起输入。
- 顶部 `↻`：立即刷新；`钉`：置顶；`⇥`：右侧吸附开关；`⚙`：0–100%背景透明度；`−`：隐藏到托盘。
- 拖动标题可移动窗口。开启吸附时松手后停靠右侧；悬停提示条展开，移出约0.6秒收起；输入时保持展开，失焦后收起。手动隐藏须从托盘重新打开。
- 每张卡片 `⌁`：展开分时曲线和分钟成交量，悬停查看数值；同一时间仅展开一只，缺失分钟不绘制假量柱。`×` 删除自选及其持仓/提醒。
- 点击股票名称：编辑买入金额、含费总成本或做T后的每股成本及持仓数量。每股成本最多8位小数，允许零或负值；金额按十进制计算、四舍五入到分。鼠标悬停持仓行查看完整成本。
- 买入金额模式按单笔委托预估佣金（默认万2.5，可修改，最低5元），沪市另估过户费；不包含买入印花税。预估与原版口径一致，实际费用以交割单为准。多笔委托请填写实际含费总成本。
- 可设上方/下方提醒价，每个方向只触发一次。提醒触发会响铃、显示系统托盘通知并保留卡片标记；Windows 专注/通知设置可能隐藏气泡。点击「重新启用提醒」再次等待触发。
- 托盘右键可显示、隐藏、刷新、添加、切换置顶/吸附、开启登录自启动、退出。关闭主窗口/Alt+F4会隐藏；完全退出用托盘「退出」。自启动默认关闭，仅用户勾选时注册到当前用户。

## 数据与可靠性

腾讯：股票报价、中文搜索、分时、上证指数。同花顺：沪深京全A涨跌家数、成交额和上一交易日同刻比较。实时接口可能限流或变更；失败会保留上次快照并自动重试，不伪造数据。没有可靠同刻基数时显示「—」。

交易及开盘准备时股票每1秒、大盘和当前分时约3秒刷新，午休30秒，休市60秒。2026休市日期与原版一致；其他年份工作日保留快速轮询并显示「日历待更新」。1秒是请求周期，不代表上游逐笔延迟。

连续竞价时源报价超过15秒标记过旧；休市明确显示快照。集合竞价以买一优先、卖一兜底估值，双侧缺失显示「—」；竞价期间暂停成交价提醒。时间倒退或超过接收时间5秒的回包不会替换缓存。提醒只使用启用后产生且不超过30秒的源报价。

持仓、自选、提醒状态和外观设置保存在 `%LOCALAPPDATA%\StockDashboard\settings.json`，不上传持仓。保存采用原子替换并保留 `.bak`；损坏记录单独隔离且保留原字段，整文件损坏会备份为 `.corrupt-时间戳.json`。整文件损坏提示在当前会话持续，核对重新录入后正常重启解除。

## Windows 适配差异

- 原生 WPF 深色圆角半透明背景，文字不透明；100%仍保留极淡点击底色。未复刻 macOS 的原生背景模糊。
- 使用 Windows 托盘通知和当前用户登录启动。展开窗口显示在任务栏，隐藏后从任务栏消失。
- 右侧吸附功能已实现，展开/收起采用立即切换，没有复制原版滑动动画。
- 不自动导入 Mac 的 UserDefaults；可手动重新录入持仓。
- 软件尚未购买代码签名证书。若目标电脑的企业策略禁止未签名程序，需要由该电脑的管理员按组织规则处理；程序不修改安全策略。
- 当前已测试本机桌面和多屏几何计算；真实不同DPI多显示器组合仍需在对应硬件验收。

## 开发与验证

```powershell
cd D:\Projects\StockDashboard\windows
.\build.ps1
.\tests.ps1          # 离线计算、解析、存储及WPF生命周期
.\tests.ps1 -Live    # 额外检查5个真实公开接口
```

构建使用 Windows 自带 `csc.exe`，不下载依赖；亦提供 `StockDashboard.Windows.csproj` 供安装了 .NET Framework 4.8 开发工具的 Visual Studio 打开。程序使用 C# 5 / WPF / HttpClient / JavaScriptSerializer / WinForms NotifyIcon。

独立测试配置可使用 `StockDashboard.exe --data-dir D:\某个测试目录`。测试脚本只使用项目 work/ 或随机临时目录，不修改正式配置。
