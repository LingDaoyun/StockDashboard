# StockDashboard Windows 设计

用户要求在 D 盘下载原版并制作同功能 Windows 版，已选择原生方案并授权直接完成细节。

## 方案与范围
采用 C# 5 + WPF / .NET Framework 4.8，Windows 10/11 桌面 EXE，使用系统自带编译器与运行环境，无第三方运行依赖。Electron 体积更大；Swift/AppKit 无法直接运行于 Windows。保留 macos 源码，新代码仅在 windows/，分支 windows-port。

行情卡片保持红涨绿跌、中文简称/代码搜索、最多20只、首次空列表；数据源、字段、竞价参考价、分时分钟量、大盘同刻比较均遵循原版。交易时股票1秒、大盘/分时3秒，午休30秒，休市60秒；6秒请求超时、同类请求不重叠、失败保留快照，源时间异常不得触发提醒。

持仓支持买入金额估费/含费总成本/每股成本；十进制计算，分位四舍五入，每股成本最多8位且可为负。提醒上下各一次，启用后30秒内源报价，竞价暂停。配置本地持久化、逐条校验、损坏原数据备份。

原生透明圆角浮窗，背景透明而文字不透明；置顶、右侧吸附提示条、悬停展开、失焦收起、可拖动、多屏边界；系统托盘、显示/隐藏、立即刷新、可选登录启动。毛玻璃尽可能使用 Windows DWM，系统不支持时回退透明背景。

## 验收与交付
提供双击可运行 EXE、便携ZIP、构建脚本、离线测试和可选在线测试、中文说明。验证解析、精度、竞价、损坏配置、重启持久化、真实行情和桌面交互。不可伪造行情或缺失量柱，不保证上游延迟。2026之外日历提示待更新。Mac历史配置自动迁移不在此次范围。
