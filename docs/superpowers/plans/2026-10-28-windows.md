# StockDashboard Windows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax for tracking.

**Goal:** 在 D 盘交付可运行的 Windows 原生股票浮窗。
**Architecture:** 独立行情模块、独立持仓与存储模块、WPF界面与原生窗口集成。
**Tech Stack:** C# 5, .NET Framework 4.8, WPF, WinForms NotifyIcon, HttpClient, JavaScriptSerializer.
**Spec:** ../specs/2026-10-28-windows-design.md

## Global Constraints
- 仅 windows/ 新实现；保持 macos 原样。新建克隆在 D:/Projects/StockDashboard，是本次工作的专用工作目录。
- namespace StockDashboard；编译器 C:/Windows/Microsoft.NET/Framework64/v4.0.30319/csc.exe，禁止 C#6+语法。
- 不修改用户的真实持仓用于测试；测试用独立临时目录。

## Review Focus
- 网络故障及晚到响应不能覆盖新股票、图表或触发旧提醒。
- 负成本与高精度成本不得经二进制浮点反算。
- 任意配置损坏不能静默清空其他持仓。
- 多屏、DPI、托盘隐藏与焦点交互不使浮窗不可找回。
- 缺少当日同刻数据、分钟断点时明确缺失。
